# ИИ и машинное обучение

Учебные материалы дисциплины для магистратуры «Бизнес-аналитика и цифровые
решения в финансах» — НИУ ВШЭ, Высшая школа бизнеса. 1 курс, модули 1–2,
2026/2027 учебный год.

## О курсе

Курс построен по следующей цепочке применения ML-решения к бизнес-задаче:

**бизнес-цель → ML-задача → данные → модель → метрики → внедрение**

Акцент делается как на ML-алгоритмах, так и на связке между техническим
решением и управленческим: как поставить задачу, на каких данных её решать,
какими метриками измерять качество модели и какое будет влияние с точки
зрения бизнес-цели. Математика даётся с полными выкладками, программирование
вынесено на семинары.

Объём — 12 лекций и 12 семинаров.

## Как работать с ноутбуками

Ноутбуки запускаются в Google Colab: достаточно аккаунта Google,
локальная установка не нужна. Дополнительные библиотеки
в Colab устанавливают первые ячейки соответствующих ноутбуков:
*catboost* в семинаре 5–6, *lime* и *shap* в семинаре 7–8.
Если запускаете ноутбуки на своём компьютере, ставьте пакеты
в отдельное окружение (для семинара 5–6 —
`pip install catboost lightgbm xgboost`; для семинара 7–8 —
`pip install numpy pandas matplotlib scikit-learn torch lime==0.2.0.1 shap==0.49.1`),
а не в окружение других проектов.

Подготовленные таблицы ноутбуки читают из папки [`data/`](data): в Colab
по прямой ссылке, при локальном запуске — из файла, если он есть рядом,
или по той же ссылке.
Таблицы уже приведены в рабочий вид (отобраны столбцы, переведены
единицы и названия). В семинаре 7–8 тексты создаются в ноутбуке, а
изображения цифр загружаются из `scikit-learn`. Источники данных указаны
рядом с соответствующими примерами.

Ячейки с заданиями содержат `...` или `raise NotImplementedError` — их надо
заменить своим кодом. В семинарах 1–2, 5–6 и 7–8 и в тренажёрах задание помечено
заголовком **Задание** (в тренажёре по *numpy* — комментарием
`# --- Задание` в начале ячейки), а самопроверка стоит в конце той же
ячейки: она печатает `✓ верно` либо подсказывает, где ошибка.

Семинар 3–4 устроен иначе: это разобранный кейс без заданий. Его читают
и запускают сверху вниз — каждый шаг опирается на результат предыдущего.
В семинаре 7–8 расчёты метрик и LIME выполняются в заданиях, а применение
SHAP и Deep SHAP показано на готовом коде.

В тренажёрах по *numpy* и по математике условие говорит только, какой
результат нужен, — какую функцию для этого применить, выбираете вы;
синтаксис ищите в шпаргалке. В тренажёрах по линейной и логистической регрессии
инструменты названы в условии: там отрабатывается не синтаксис, а порядок
работы с данными.

Если в ходе работы выполнение кода приводит к неожиданным ошибкам, первое
действие — «Перезапустить среду выполнения и выполнить всё»
(Runtime → Restart and run all). Почти все неожиданные ошибки объясняются
тем, что ячейки выполнялись **не по порядку**.

```
О_итог = 0,10 · Посещаемость + 0,20 · Проверочные + 0,25 · Практические + 0,15 · Тест + 0,30 · Проект
```

| Элемент контроля | Вес | Формат |
|---|---|---|
| Посещаемость | 10 % | лекции и семинары обоих модулей |

Итоговый проект — **блокирующий** элемент контроля: сквозное ML-решение,
презентация и защита, на которой вопросы задаются каждому участнику команды.
