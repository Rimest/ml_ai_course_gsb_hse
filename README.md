# ИИ и машинное обучение

Учебные материалы дисциплины для магистратуры «Бизнес-аналитика и цифровые
решения в финансах» — НИУ ВШЭ, Высшая школа бизнеса. 1 курс, модули 1–2,
2026/2027 учебный год.

## О курсе

Курс построен по следующей цепочке применения ML-решения к бизнес-задаче:

**бизнес-цель → ML-задача → данные → модель → метрики → внедрение**

Акцент делается как на ML-алгоритмах, так и на связке между техническим
решением и управленческим: как поставить задачу, на каких данных её решать,
какими метриками измерять качество модели и какое будет влияние с точки
зрения бизнес-цели. Математика даётся с полными выкладками, программирование
вынесено на семинары.

Объём — 12 лекций и 12 семинаров.

## Как работать с ноутбуками

Ноутбуки подходят для Google Colab — устанавливать ничего не нужно,
достаточно аккаунта Google.

Ячейки с заголовком **Задание** содержат `...` или `raise NotImplementedError` —
их надо заменить своим кодом. Сразу под каждым заданием стоит ячейка
самопроверки: она печатает `✓ верно` либо подсказывает, где ошибка.

Если в ходе работы выполнение кода приводит к неожиданным ошибкам, первое
действие — «Перезапустить среду выполнения и выполнить всё»
(Runtime → Restart and run all). Почти все неожиданные ошибки объясняются
тем, что ячейки выполнялись **не по порядку**.

## Оценивание

```
О_итог = 0,10 · Посещаемость + 0,20 · Проверочные + 0,25 · Практические
       + 0,15 · Тест + 0,30 · Проект
```

| Элемент контроля | Вес | Формат |
|---|---|---|
| Посещаемость | 10 % | лекции и семинары обоих модулей |
| Аудиторные проверочные | 20 % | четыре работы по 10 минут |
| Практические задания | 25 % | четыре индивидуальных задания |
| Итоговый тест | 15 % | по всем пройденным темам |
| Итоговый проект | 30 % | команда 2–3 человека, защита |

Итоговый проект — **блокирующий** элемент контроля: сквозное ML-решение,
презентация и защита, на которой вопросы задаются каждому участнику команды.
